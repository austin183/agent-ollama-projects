# Code Review Skill Checklist

## Skill Structure

- [ ] `SKILL.md` exists and is properly formatted
- [ ] YAML frontmatter includes `name` and `description`
- [ ] Description is under 100 characters
- [ ] Checklist section exists with actionable items

## SOLID Principles Coverage

- [ ] Single Responsibility Principle is covered
- [ ] Open/Closed Principle is covered
- [ ] Liskov Substitution Principle is covered
- [ ] Interface Segregation Principle is covered
- [ ] Dependency Inversion Principle is covered

## Separation of Concerns Coverage

- [ ] Layering is discussed
- [ ] Cohesion is addressed
- [ ] Coupling is covered
- [ ] Single source of truth is mentioned

## Review Process

- [ ] Step-by-step review process is documented
- [ ] High-level design review steps are included
- [ ] Detailed code review steps are included
- [ ] Feedback guidelines are provided
- [ ] Approval decision criteria are clear

## Quality Elements

- [ ] Common red flags section exists
- [ ] Code examples are provided
- [ ] Tips section offers practical advice
- [ ] When NOT to use section is included

## Formatting

- [ ] Tables are used for clarity where appropriate
- [ ] Checkboxes are used for actionable items
- [ ] Code blocks use proper syntax highlighting
- [ ] Links to related skills are included
