# agent-ollama-projects
Things I used Claude Code and other agentic tools to do with Ollama

# Claude Harness
Where I am trying to come up with some reusable things to make Claude a bit better at doing its thing so I can think even less!

# How to Use
Put your project in the workspace folder and run Claude Code from the claudeharness folder.  Use claudeharness for developing skills across projects and the workspace for developing skills for project specific things.
