# Issues with Crop Overlay misalignment with Preview Panel
1.  On Diagonal Slices Layout, when the panel is clipped due to reaching the edge of the preview frame, the crop overlay is not similarly clipped.  So a triangle shaped panel still looks like a parallelogram in the crop overlay.  

2.  On Hexagonal Layout, instead of the crop overlay looking like a hexagon, it looks like an X or an hourglass.
