# The Right Hand Side Bar Should have Collapsible Sections
There are may controls along the right hand side of the Collage Maker.  It would be good if they were organized into sections and each section start out as collapsed so the user can see all the options available.  Reorder them to:

- Layout
- Title
- Crop
- Background
- Overlay
- Export

# Panel Selection behavior
When the user select a panel, if the Crop is collapsed, it should be expanded and scrolled into view.
