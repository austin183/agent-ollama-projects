# Title Work
## Title Positioning and resizing
The Title should have a box that is visible when the user hovers over it.
- The user can grab the title anywhere within the box to reposition it on the canvas
- The user can grab the left and right sides of the box to expand or shrink the area covered by the box
- When the Background color checkbox is on, the background covers the extent of the box as the user extended it or contracted it
- When the user changes the left / center / right settings, the title aligns within the box as opposed to the whole canvas
