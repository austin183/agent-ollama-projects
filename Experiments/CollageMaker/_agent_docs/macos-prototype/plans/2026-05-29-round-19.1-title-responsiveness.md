# Round 19.1: Title Drag and Resize Responsiveness

**Date**: 2026-05-29
**Change Request**: `_agent_docs/change-requests/round-19.1.md`
**Inspired by**: Session 61 (overlay crop debounce pattern)

## Problem

When dragging or resizing the title via `DragGesture.onChanged`, `titleStyle.didSet` calls `updatePreview()` on every tick (~60Hz), triggering:
1. Full collage re-composite (all panels, background, title)
2. Background re-render
3. Title image re-render at full canvas resolution

This causes CPU spikes and visible lag during title drag/resize.

## Root Cause

In `CollageViewModel.swift` line 92:
```swift
var titleStyle: TitleStyle = .default {
    didSet {
        // ... undo registration (skipped during drag) ...
        debouncedSave()
        updatePreview()   // <-- fires on every gesture tick
    }
}
```

The `isDraggingTitle` guard only skips undo registration, not `updatePreview()`.

## Solution: Skip Full Composite During Drag + SwiftUI Live Overlay

Unlike the panel crop overlay (which reads live `cropMap` data from SwiftUI), the title is rendered as a flat `NSImage` at a fixed position. Simply skipping `updatePreview()` would make the title invisible during drag. The fix has two parts:

### Part 1: Guard `updatePreview()` During Drag

Add `isDraggingTitle` guard around `updatePreview()` in `titleStyle.didSet`. During drag, only update the lightweight SwiftUI overlay position.

### Part 2: SwiftUI Live Title Overlay During Drag

Show a SwiftUI `Text` overlay that tracks `titleStyle` position/width in real-time. `titleCanvasFrame` is already computed live from `titleStyle`, so the frame math is free. The SwiftUI text overlay renders in <5ms per frame, well within the 60Hz budget.

## Target Behavior

```
During drag:
  titleStyle onChanged → update position only (no updatePreview)
  SwiftUI reads titleStyle → computes titleCanvasFrame → positions Text overlay instantly

On gesture end:
  updatePreview() + updateTitleImage() → composite final position
  Hide SwiftUI overlay, show pre-rendered titleImage
```

## Files to Modify

### 1. `ViewModel/CollageViewModel.swift`

**In `titleStyle.didSet`** (line 92):
- Guard `updatePreview()` behind `!isDraggingTitle`
- Only `debouncedSave()` fires during drag (already debounced at 300ms)

```swift
var titleStyle: TitleStyle = .default {
    didSet {
        guard !isInitializing else { return }
        if !isDraggingTitle {
            undoManager.registerUndo(withTarget: self) { target in
                target.titleStyle = oldValue
            }
            undoManager.setActionName("Change Title Style")
            updatePreview()
        }
        debouncedSave()
    }
}
```

### 2. `Views/CollageEditorView.swift`

**In `DragGesture.onEnded`** (line 308):
- Add `viewModel.updatePreview()` to composite final title position after drag completes

**In body ZStack** (line 106):
- During drag: show SwiftUI `Text` overlay that reads live `titleStyle`
- Not during drag: show pre-rendered `titleImage` as before

The live overlay uses the existing `titleCanvasFrame` computed property + `canvasToPreviewFrame` to position a SwiftUI `Text` with matching font/color/alignment attributes.

```swift
// In body, replace the titleImage block:
if viewModel.isDraggingTitle, let scaled = titleFrame, !viewModel.title.isEmpty {
    // Live SwiftUI text overlay — follows cursor instantly
    Text(viewModel.title, in: .init())
        .frame(width: scaled.width)
        .position(x: scaled.midX, y: scaled.midY)
} else if let titleImg = viewModel.titleImage {
    // Pre-rendered title image (used when not dragging)
    Image(nsImage: titleImg)
        .resizable()
        .aspectRatio(contentMode: .fit)
        .frame(width: geometry.size.width, height: geometry.size.height)
}
```

**Note**: The SwiftUI `Text` overlay won't match the CG-rendered title pixel-perfectly (background rect, exact font metrics), but it provides smooth visual feedback during drag. The final composite on gesture end restores the accurate rendering.

## Implementation Order

1. Add `isDraggingTitle` guard around `updatePreview()` in `titleStyle.didSet`
2. Add `viewModel.updatePreview()` to `DragGesture.onEnded` for title
3. Add SwiftUI `Text` overlay during drag in body ZStack
4. Build and verify
5. Test: title drag responsiveness, title resize responsiveness, final position accuracy

## Risks and Mitigations

1. **SwiftUI Text vs CG text mismatch**: The live overlay uses SwiftUI `Text` which may render slightly differently than `NSAttributedString.draw(in:)`. This is acceptable — the overlay is transient (only during drag), and the final composite on gesture end restores the accurate rendering.

2. **Missing background rect during drag**: The CG-rendered title includes a rounded background rect when `showBackground = true`. The SwiftUI overlay won't include this. Acceptable tradeoff for responsiveness.

3. **Title flicker on gesture end**: When `isDraggingTitle` flips from `true` to `false`, the overlay disappears and `titleImage` appears. Since `updatePreview()` is async, there may be a brief frame where neither is visible. The existing `titleImage` (from pre-drag) will still be visible, so no flicker.

4. **Resize handle hit area**: The orange resize handles are already gated by `!viewModel.isLiveGesturing`. Need to ensure they remain visible during title drag (they should be, since `isLiveGesturing` is for panel gestures, not title).
