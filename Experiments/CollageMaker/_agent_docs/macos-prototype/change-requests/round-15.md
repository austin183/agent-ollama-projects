# Performance Degradation Issues
- Add Images to Collage Maker
- Make several Edits to several pictures
  - Move and Resize with cursor in panel editor
  - Move and Resize with gestures in main image
- Continue switching panels and making edits
- Try changing the location and size of the Title as well

Over time, the responsiveness of edits stop being immediate and take longer and longer to update with user input as the number of inputs grows.

Also the memory usage jumps from about 250MB when first adding images to between 500MB and 780MB when the lag becomes noticeable.
