# Round 8 Implementation Plan

## 1. Text Alignment Fix (Center/Right)

**Files:** `CollageAssembler.swift`, `CollageEditorView.swift`

**Problem:** `CollageAssembler.drawTitle` (lines 412-429) measures `boundingRect(with: drawWidth)` then computes a manual `textOffsetX` based on alignment. When text fills or wraps within `drawWidth`, `boundingBox.width == drawWidth`, so `textOffsetX == 0` for all alignments — text always renders left-aligned regardless of the picker setting.

**Fix:** Switch from `draw(at:)` + manual offset to `draw(in:)`, which respects `paragraphStyle.alignment` natively. Per the NSAttributedString skill reference, both `draw(at:)` and `draw(in:)` treat Y as baseline, so the Y calculation stays the same.

**Changes in `CollageAssembler.swift:423-453`:**
- Remove the `textOffsetX` switch block (lines 423-430)
- Replace `attributedString.draw(at: CGPoint(x: drawX + textOffsetX, y: baselineY))` with:
  ```
  attributedString.draw(in: CGRect(x: drawX, y: baselineY, width: drawWidth, height: boundingBox.height))
  ```
- Background box stays at full `drawWidth` (alignment moves text inside the fixed box, per skill reference rule #9)

**Changes in `CollageEditorView.swift:41-78`:**
- `titleCanvasFrame` already returns the full-width box at `drawX` — no alignment-based X offset. This is correct behavior and needs no change.
- `titleMinWidth` (lines 80-103) also needs no change.

## 3. Partial Text Styling (Bold/Italic/Underline + Live Preview)

**Files:** `TitleStyle.swift`, `CollageViewModel.swift`, `ExportPanel.swift`, `CollageAssembler.swift`, `CollageEditorView.swift`, new file `AttributedStringEditor.swift`

This is the largest change. Core idea: replace `title: String` with `titleAttrString: NSAttributedString` throughout the stack. Replace `TextEditor` with a custom `NSTextView`-based editor that renders styled text live.

### 3a. Model Changes

**`TitleStyle.swift`:**
- Keep `fontFamily`, `fontSize`, `fontColor` as *default attributes* applied to new/selected text
- Keep `backgroundColor`, `showBackground`, `alignment`, `positionX`, `positionY`, `width`
- Remove any whole-text style flags (none exist yet, so no removal needed)

### 3b. ViewModel Changes

**`CollageViewModel.swift:48-53`:**
- Replace `title: String` with `titleAttrString: NSAttributedString`
- Persist via `NSKeyedArchiver` to a new UserDefaults key `"titleAttrString"`
- Provide computed property `var title: String { titleAttrString.string }` for backward compat with assembler calls
- On first load: if `"titleAttrString"` key is missing but old `"title"` key exists, migrate by creating an `NSAttributedString` from the old string using current `titleStyle` defaults

### 3c. Custom Text Editor

**New file: `AttributedStringEditor.swift`**
- `NSViewRepresentable` wrapping AppKit `NSTextView`
- Binds to `Binding<NSAttributedString>` via a coordinator
- Coordinator observes `NSTextStorage` changes via `NSTextStorageDelegate` to push updates back to SwiftUI
- `updateNSView` must compare `textView.textStorage` with the binding value via `isEqual` to avoid resetting cursor/selection on every render
- Should support standard editing: typing, selection, paste, etc.
- Frame: `minHeight: 50`, styled to match current `TextEditor` appearance (padding, background, border)

### 3d. Style Toolbar

**`ExportPanel.swift`:**
- Add a row of toggle buttons above the text editor: Bold, Italic, Underline
- Each button applies/removes its style to the *current selection range* in the `NSTextView`
- Style application logic:
  - **Bold:** `NSFontManager.shared.convert(font, toHaveTrait: .boldTrait)` on selection range
  - **Italic:** `NSFontManager.shared.convert(font, toHaveTrait: .italicTrait)` on selection range
  - **Underline:** Toggle `.underlineStyle` attribute (0 vs `.single.rawValue`) on selection range
- Buttons should reflect the style state of the *current selection* (or insertion point if no selection)
- Need to expose the `NSTextView`'s `selectedRange` and `textStorage` through the representable for style queries

### 3e. Rendering

**`CollageAssembler.swift:391-454`:**
- `drawTitle` receives the `NSAttributedString` directly
- Still needs to apply `paragraphStyle.alignment` to any ranges that don't already have a paragraph style
- Apply default `fontFamily`, `fontSize`, `fontColor` to any ranges missing those attributes
- Use `draw(in:)` for alignment support (from Change 1)
- Bounding box measurement should use the attributed string as-is (with paragraph style alignment set)

**`CollageAssembly` protocol:**
- Update `assemble` and `assemblePreview` signatures to accept `NSAttributedString` for title
- Update `assembleWithCGImages` and `assemblePreviewWithCGImages` similarly

**`CollageEditorView.swift:41-78`:**
- `titleCanvasFrame` measurement should use the attributed string's bounding box directly
- Font lookup for measurement should use the attributed string's effective font at position 0

### 3f. Persistence & Migration

**`CollageViewModel.swift`:**
- New UserDefaults key: `titleAttrString`
- Archival: `NSKeyedArchiver.archivedData(withRootObject: titleAttrString, requiringSecureCoding: false)`
- Migration on init: if `titleAttrString` key missing but `title` key present, create attributed string from old plain text using current `titleStyle` defaults

## Risks and Considerations

1. **NSAttributedString persistence:** `NSKeyedArchiver` with `requiringSecureCoding: false` matches the existing `NSColor` pattern in the codebase. Acceptable risk for local-only storage.

2. **NSTextView in SwiftUI:** `updateNSView` must avoid resetting cursor/selection. Compare via `textStorage.isEqual` before updating. May need to save/restore `selectedRange` around updates.

3. **Font trait conversion:** `NSFontManager.convert(toHaveTrait:)` may not find bold/italic variants for all custom font families. Should gracefully fall back to the base font.

4. **Assembler protocol change:** Affects `CollageAssembly` protocol, `CollageAssembler` implementation, and `CollageViewModel` caller sites in `updatePreview()` and `exportCollage()`.

5. **Backward compatibility:** Users with saved `title` in UserDefaults need migration to `NSAttributedString` on first launch after update.

6. **Style buttons and selection sync:** The `AttributedStringEditor` representable needs to expose the current selection range so style buttons can query current style state and apply changes. This requires a coordinator that bridges `NSTextView.delegate` selection change events.
