## Step 5: Fix `applyPinch` effective-origin clamping (Finding #1)

**File:** `CollageMaker/CollageMaker/ViewModel/CropManager.swift`

**Lines 223-232:** Replace center-based clamping with effective-origin clamping to match `applyPan`:

**Before:**
```swift
let visBounds = computeVisibleSourceBounds(destRect: crop.destinationRect, sourceW: scaledW, sourceH: scaledH)

let currentCenterX = crop.sourceRect.midX
let currentCenterY = crop.sourceRect.midY

let maxOX = max(0, image.size.width - scaledW)
let maxOY = max(0, image.size.height - scaledH)

let newOX = clamp(currentCenterX - scaledW / 2, min: 0, max: maxOX)
let newOY = clamp(currentCenterY - scaledH / 2, min: 0, max: maxOY)
```

**After:**
```swift
let visBounds = Self.computeVisibleSourceBounds(destRect: crop.destinationRect, sourceW: scaledW, sourceH: scaledH)

let currentCenterX = crop.sourceRect.midX
let currentCenterY = crop.sourceRect.midY

let effectiveCenterX = currentCenterX + visBounds.offsetX
let effectiveCenterY = currentCenterY + visBounds.offsetY
let maxEffX = max(0, image.size.width - visBounds.visibleW)
let maxEffY = max(0, image.size.height - visBounds.visibleH)

let newEffX = clamp(effectiveCenterX - visBounds.visibleW / 2, min: 0, max: maxEffX)
let newEffY = clamp(effectiveCenterY - visBounds.visibleH / 2, min: 0, max: maxEffY)

let newOX = newEffX - visBounds.offsetX
let newOY = newEffY - visBounds.offsetY
```

**Behavioral change:** Pinch-to-zoom on off-canvas `.path` panels will now use effective-origin clamping, matching `applyPan`. For fully on-canvas `.rect` panels, `visBounds.offset` is `.zero` and `visBounds.visible` equals `scaledW/H`, so behavior is unchanged.

## Step 6: Extract `drawClampedCrop` helper (Finding #5)

**File:** `CollageMaker/CollageMaker/Services/CollageAssembler.swift`

**Add private helper** (after `drawPanels`, ~line 361):
```swift
private func drawClampedCrop(context: CGContext, cgImage: CGImage, sourceRect: CGRect, destRect: CGRect) {
    let imageBounds = CGRect(x: 0, y: 0, width: cgImage.width, height: cgImage.height)
    let clamped = sourceRect.intersection(imageBounds)
    guard clamped.width > 0, clamped.height > 0,
          let clippedCrop = cgImage.cropping(to: clamped) else { return }
    let drawX = destRect.origin.x + (clamped.origin.x - sourceRect.origin.x) / sourceRect.width * destRect.width
    let drawY = destRect.origin.y + (clamped.origin.y - sourceRect.origin.y) / sourceRect.height * destRect.height
    let drawW = clamped.width / sourceRect.width * destRect.width
    let drawH = clamped.height / sourceRect.height * destRect.height
    context.draw(clippedCrop, in: CGRect(x: drawX, y: drawY, width: drawW, height: drawH))
}
```
