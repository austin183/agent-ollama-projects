# Checklist for Capturing Learnings

Before saving your debrief documentation, verify:

## Completeness
- [ ] Exercise is fully completed before debriefing
- [ ] All four sections answered (What Worked, What Didn't Work, What Was Confusing, Skill Mapping)
- [ ] Insights are specific and concrete, not vague
- [ ] Each category has at least one substantive point

## Organization
- [ ] Answers organized by category
- [ ] Skill mapping identifies specific Skills to update
- [ ] Actionable items are clear and specific
- [ ] Documentation format is appropriate for the content

## Documentation
- [ ] Debrief saved with date and purpose
- [ ] Clear section headers used
- [ ] Status field set (Open/Closed/In Progress)
- [ ] Follow-up section identifies related tasks

## Follow-through
- [ ] Identified improvements are tracked
- [ ] Related exercises or tasks noted
- [ ] Follow-up action items documented
- [ ] Learnings can be easily found and referenced

## Quality
- [ ] Learnings are specific to the exercise context
- [ ] Patterns are generalized where appropriate
- [ ] Avoids redundant information
- [ ] Focuses on lessons that apply to future work
