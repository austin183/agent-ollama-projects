# Archive Script Syntax Error Fix

## Issue Summary

The `archive_script.sh` file generated by `scripts/archive_files.py` has a syntax error related to quotes in file paths.

### Error Message

```
unexpected EOF while looking for matching `''
syntax error: unexpected end of file
```

## Root Cause

The `format_path_for_shell()` function in `scripts/archive_files.py` does not properly escape quotes in file paths, causing bash parsing errors.

### Failed Approach 1: Single Quotes

Attempted to wrap paths in single quotes: `return f"'{path}'"`

**Result:** FAILED. The script still threw errors despite this approach handling apostrophes correctly in isolation.

## Next Approach: Double Quotes with Proper Escaping

### Correct Function (TO BE IMPLEMENTED)

```python
def format_path_for_shell(path: str):
    """
    Format path for bash script with proper escaping.

    Uses double quotes around paths and escapes only necessary characters.
    Double quotes allow spaces and apostrophes without complex escaping.
    """
    # Escape backslashes and double quotes
    # Dollar signs, backticks, and newlines need escaping
    escaped = path.replace("\\", "\\\\").replace('"', '\\"').replace('$', '\$').replace('`', '\\`')
    return escaped
```

**Rationale:** Double quotes allow spaces and apostrophes without needing to escape them. We only need to escape backslashes, double quotes, dollar signs, backticks, and newlines.
