# DupeRemoval Development Worklog

## Project Overview

DupeRemoval is an experimental Python project for intelligent duplicate file detection and removal using Claude Code and Ollama (local LLMs).

## Data Source

This tool is specifically tailored for duplicate data generated by **dupeguru.app** (installed via Homebrew: `brew install dupeguru`), available at https://dupeguru.voltaicideas.net/.

## Development History

### Phase 1: Initial Planning (GLM4.7-flash-plan.md)

**Date:** Initial planning session
**Status:** Completed

Created the original plan for duplicate folder categorization using Bash script:

1. **Input:** `workspace/LocalHDDuplicates.csv` - Contains duplicate file entries with:
   - Group ID: Identifies duplicate groups
   - Filename: File name
   - Folder: Full path to file
   - Size (KB): File size
   - Match %: Similarity percentage

2. **Output:** `workspace/DuplicateAnalysis.csv` - Per-duplicate-group analysis

3. **Categorization Rules:**
   - **Keep folders (main sources):** Pictures, Photos, Documents, Music, Videos, Movies, Home, Desktop, Downloads
   - **Archive folders (backups/secondary sources):** PhoneCopy, ExternalBackup, Archive, Temp, Backups
   - **Mixed/Unknown:** Flag for manual review

4. **Decision Logic:**
   - One main source folder → KEEP
   - All backups → ARCHIVE (manual review)
   - Mixed main/backup → Main as KEEP, backups as ARCHIVE

**Key Decisions Made:**
- Folder cleanup: No - keep redundant folder paths as-is
- Path normalization: No - preserve original folder structure including duplicates
- Pattern-based pre-categorization using regex

### Phase 2: Implementation (analyze_duplicates.py)

**Date:** After initial planning
**Status:** ✓ Complete

Converted the Bash plan to Python (scripts/analyze_duplicates.py):

- Uses regex patterns `MAIN_PATTERN` and `BACKUP_PATTERN` to categorize folders
- Reads CSV handling quoted fields with embedded commas
- Groups entries by Group ID
- Outputs DuplicateAnalysis.csv with decision and rationale

**Pattern Definitions (from GLM4.7-flash-plan.md):**
```python
MAIN_PATTERN = re.compile(r"Pictures|Photos|Documents|Music|Videos|Movies|Home|Desktop|Downloads|DaVinci")
BACKUP_PATTERN = re.compile(r"PhoneCopy|ExternalBackup|Archive|Temp|Backups|Bacup|photoslibrary")
```

### Phase 3: Second Script (focused_duplicates.py)

**Date:** After analyze_duplicates.py
**Status:** ✓ Complete

Created focused_duplicates.py to filter for fully consistent groups:

- Reads DuplicateAnalysis.csv
- Filters groups where ALL entries have the same decision
- Output: FocusedDuplicates.csv

**Intended Behavior:**
- Single-entry groups → automatically qualify
- Groups with consistent decisions → qualify
- Mixed decision groups → excluded

### Phase 4: Bug Discovery (CriticalIssueFound.md)

**Date:** After focused_duplicates.py completed
**Status:** Bug Identified → ✓ Fixed

**Original Issue Found:**

The focused_duplicates.py script had a bug where mixed groups were incorrectly retained.

**Examples of mixed groups incorrectly kept:**
- Group ID: 3856 (ARCHIVE + KEEP entries)
- Group ID: 3858 (mixed ARCHIVE and KEEP)
- Group IDs: 3860, 3861, 3862, 3863, 4664, 5131, 5133

**Statistics:**
- 5,524 total groups analyzed
- 613 entries from "fully consistent groups"
- ~4,911 entries were mixed groups that should have been excluded

**Original Logic Flaw:**
The script kept single-entry groups and groups with mixed decisions, but the output showed mixed decisions being retained.

**Status:** ✓ FIXED - All Python scripts now work as expected.

### Phase 7: AI Decision Script (ai_decision.py)

**Date:** During development
**Status:** Implemented

Uses Ollama's gpt-oss:20b model for intelligent keep/archive decisions:

- Reads FocusedDuplicates.csv
- Groups entries by Group ID
- Calls Ollama for each group
- Writes AIDecisions.csv with AI-generated decisions and rationales

**AI Decision Guidelines:**
- Prefer files without UUIDs
- Prefer categorized files over Uncategorized
- Avoid numeric filenames when real filenames exist
- Prefer higher match percentage
- Consider file size (larger = more complete)
- Prioritize main source folders over backups
- Special handling for DaVinci Resolve CachedClips
