# DupeRemoval

An experimental Python project built with Claude Code, Ollama, and GLM 4.7 Flash 30b for intelligently deciding which versions of duplicated files should be removed. Uses local LLMs instead of subscription-based services.

This tool is specifically tailored for duplicate data generated by **dupeguru.app** (installed via Homebrew: `brew install dupeguru`), available at https://dupeguru.voltaicideas.net/.

## Overview

This tool helps you identify and manage duplicate files on your local storage by analyzing file similarity and making intelligent decisions about which files to keep vs. archive. The AI-powered approach considers factors like file content, location, naming patterns, and quality metrics to provide reasoned recommendations.

## Features

- **Duplicate Detection**: Scans directories for duplicate files based on content similarity
- **AI-Powered Decision Making**: Uses Ollama's LLM (e.g., gpt-oss:20b) to intelligently recommend which files to keep
- **Pattern-Based Pre-categorization**: Heuristic rules to pre-categorize files based on folder names (main source vs. backup)
- **Rationale Tracking**: Each decision includes an AI-generated rationale explaining why a file was chosen
- **Batch Processing**: Processes large numbers of duplicate file groups efficiently

## Workflow

```
1. Export Duplicates to CSV with DupeGuru → LocalHDDuplicates.csv
2. Pre-categorize with Claude Code in Plan Mode so it identifies common archive patterns → DuplicateAnalysis.csv (pattern-based)
3. Filter Groups where common archive patterns left everything as KEEP → FocusedDuplicates.csv
4. Use AI Decisions to break ties on the focused set → AIDecisions.csv (keep/archive recommendations)
5. Merge AI Decisions
5. Apply Decisions → Archive selected files
```

## Usage

Run the scripts in order:

```bash
# Step 1: Analyze duplicates and apply pattern-based rules
python scripts/analyze_duplicates.py

# Step 2: Filter for fully consistent groups
python scripts/focused_duplicates.py

# Step 3: Generate AI decisions using local LLM
python scripts/ai_decision.py

# Step 4: (Optional) Apply decisions and archive files
python scripts/archive_files.py
```

## Scripts

| Script | Description |
|--------|-------------|
| `analyze_duplicates.py` | Reads duplicate detection results, applies pattern-based heuristics, outputs categorized decisions |
| `focused_duplicates.py` | Filters `DuplicateAnalysis.csv` for groups where all entries have consistent decisions |
| `ai_decision.py` | Uses Ollama LLM to analyze focused duplicate groups and make intelligent keep/archive decisions |
| `archive_files.py` | Applies decisions from `AIDecisions.csv` to archive selected files |
| `extract_group_ids.py` | Extracts unique group IDs from duplicate data |
| `filter_application_groups.py` | Filters application-specific groups for targeted processing |
| `filter_by_group_ids.py` | Filters duplicates based on specified group IDs |
| `merge_ai_decisions.py` | Merges multiple AI decision CSV files |
| `focused_duplicates.py` | Produces FocusedDuplicates.csv with fully consistent groups |

## AI Decision Guidelines

The AI considers the following factors when making decisions:

- Prefer files without UUIDs (e.g., `2448E946-8B54-46FF-A46D-8F5CEEAA917A`) over those with UUIDs
- Prefer categorized files over Uncategorized
- Avoid numeric filenames when real filenames exist
- Prefer higher match percentage (100% > 95%)
- Consider file size (larger files may be more complete)
- Prioritize main source folders over backup locations
- Special handling for DaVinci Resolve CachedClips

## Customization

### Modifying Pattern Rules

Edit `analyze_duplicates.py` to customize pattern matching:

```python
MAIN_PATTERN = re.compile(r"Your pattern here")
BACKUP_PATTERN = re.compile(r"Your pattern here")
```

### Changing the LLM Model

Edit `ai_decision.py` to use a different model:

```python
MODEL_NAME = "your-model:tag"
```

### Adjusting AI Temperature

The AI temperature controls randomness in decisions. Lower values (e.g., 0.1) produce more consistent results.

## Output Format

All CSV outputs follow this structure:

```
Group ID,Folder,Filename,Size (KB),Match %,Decision,Rationale
```

- `Group ID`: Unique identifier for duplicate set
- `Folder`: Source folder path
- `Filename`: File name
- `Size (KB)`: File size in kilobytes
- `Match %`: Content similarity percentage
- `Decision`: KEEP, ARCHIVE, or MANUAL
- `Rationale`: Human-readable explanation
