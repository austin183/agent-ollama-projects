## Learnings for Building a Capturing-Learnings Skill

### Core Concepts to Capture

1. **Debrief Template** - Structured questions to ask after completing an exercise
2. **Pattern Categories** - How to categorize learnings (what worked, what was missing, what was confusing)
3. **Skill Mapping** - How to translate learnings into skill improvements
4. **Documentation Format** - Structured way to save learnings for future reference

### Workflow Pattern

```
1. Complete exercise →
2. Run capturing-learnings →
3. Clear context →
4. Build/refine skill →
5. Iterate
```

### Key Insight

The skills-best-practice skill teaches that skills should be built iteratively with real-world use. A capturing-learnings skill is essential for this loop because:
- Context gets cluttered after exercises
- Insights need to be persistent
- Need systematic way to improve skills
- Clear record of what worked/failed for future reference
