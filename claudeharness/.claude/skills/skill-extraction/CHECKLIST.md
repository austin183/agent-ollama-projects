# Skill Extraction Checklist

Use this checklist to verify quality after running the extraction script.

## Preamble Quality (Before Extraction)

- [ ] Preamble describes the type of skills to extract
- [ ] Preamble specifies output format and sections
- [ ] Preamble includes quality standards
- [ ] Preamble defines what to avoid (common pitfalls)

## Source Documents

- [ ] Source documents are well-structured markdown
- [ ] Source documents contain code examples
- [ ] Source documents have troubleshooting sections
- [ ] Source documents are focused on specific skills

## Extracted Output

### Header Section
- [ ] Skill name is a gerund (verb + -ing)
- [ ] Skill name is lowercase with hyphens
- [ ] Description is under 100 characters
- [ ] Description is in third-person
- [ ] Priority is HIGH, MEDIUM, or LOW

### Summary Sections
- [ ] Focus Areas has 3 specific, actionable items
- [ ] Key Topics has 3 concrete topics (not abstract)
- [ ] Use Cases describes real-world scenarios

### Content Section
- [ ] Prerequisites lists all required setup
- [ ] Step-by-step Instructions has numbered steps with commands
- [ ] Code Examples has syntax highlighting
- [ ] Configuration Details has real values (URLs, paths, commands)
- [ ] Troubleshooting includes actual error messages and solutions
- [ ] Tips section contains 2+ actionable notes

## Quality Verification

- [ ] Content is skill-specific, not project-specific
- [ ] All placeholders have been replaced with real information
- [ ] Code examples are testable and complete
- [ ] Commands work when copied/pasted
- [ ] Terminology is consistent throughout
- [ ] No markdown syntax errors

## Post-Processing

- [ ] Review the extracted file for clarity
- [ ] Test any code examples
- [ ] Verify configuration values are accurate
- [ ] Add any missing context from source
- [ ] Save the preamble for future use
