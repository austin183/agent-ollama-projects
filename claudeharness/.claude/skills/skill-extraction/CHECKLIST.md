# Extraction Checklist

Before sharing a skill-extraction result:

- [ ] Only extracted skill-specific content from the document
- [ ] Generated clear, actionable content from the details
- [ ] Used proper naming convention (gerund, lowercase, hyphens)
- [ ] Description is concise (under 100 characters), third-person
- [ ] Priority is clearly specified
- [ ] Focus areas and key topics are specific and actionable
- [ ] Use cases describe concrete contexts
- [ ] Related plan sections are exact names from the source
- [ ] Rationale explains why the skill matters
- [ ] Content includes all required sections (prerequisites, steps, examples, configuration, troubleshooting, tips)
- [ ] Follows template structure (skill_name, description, priority, focus_areas, key_topics, use_cases, related_plan_sections, rationale, content)
- [ ] Content subsections include: Prerequisites, Step-by-step Instructions, Code Examples, Configuration Details, Troubleshooting, Tips
- [ ] Code blocks have proper syntax highlighting
- [ ] URLs, paths, and commands are preserved exactly
- [ ] Use consistent terminology throughout
- [ ] Output is valid markdown following the template structure
